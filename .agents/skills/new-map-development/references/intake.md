# 确认与资料表

按本次范围填写，用户已经给出的信息直接转录，没有涉及的可选项标“不适用”。代理先查已有资料，再集中询问会改变结果的缺口。

## 地图必确认

| 主题 | 用户决定或提供 | 代理查找、提案与核验 |
| --- | --- | --- |
| 用途与范围 | 地图名、章节位置、玩家来此做什么；本次仅设计还是接入；排除项 | 唯一区域标识、前置条件、最小可演示流程 |
| 区域连接 | 从哪图哪个出口进入、出口列表、返回哪里、解锁条件；是否保留未开放接口 | 连接图、出生/返回点、安全距离、取消行为、战斗时能否离场；区分换图和探索结算 |
| 地形 | 可走地面、水域、障碍、窄路和高差；是否减速或允许穿越 | 像素与世界坐标、脚底半径、碰撞、连通性、速度与脚印/水波方案 |
| 地图界面 | 总图位置、地图解锁/迷雾、路标和资源标记 | 小图与展开图共用投影，用独立地标核对而不只验证自身锚点 |
| 生命周期 | 同趟往返、退出读档、下一趟哪些状态保留/重置 | 位置、探索状态、迁移、非法位置回退、保存失败回滚 |

地图素材提供：未标注原始底图、实际尺寸、参考图及借鉴特征；另附入口/出口/通路/障碍/怪物/资源/剧情区标注图。若只有口述，由代理制作点位方案供确认。标注图不直接作为生产底图或像素碰撞遮罩。

分层素材按需提供前景遮挡、栅栏、路标、交互物、地面效果；说明透明背景、层级及相对角色比例。已有素材给仓库相对路径或附件，待生成素材说明用途和参考，由代理拟提示词。实际尺寸收到文件后测量，不把提示词要求尺寸当输出尺寸。

## 有怪物时逐种填写

| 主题 | 必须确认的内容 |
| --- | --- |
| 身份与布局 | 名称、普通怪/首领、元素、数量、固定/随机出生、活动范围；入口/剧情/资源避让 |
| 移动 | 待机/巡游/追击/回位，激怒与脱战条件、是否回血；水陆通行、跨岸、穿障与怪物间避让 |
| 攻击 | 近战/弹道/范围/跳跃等模式，前摇/预警、锁向、射程、遮挡、间隔、可躲避方式、单次伤害次数、白闪/击退与死亡反馈 |
| 数值 | 生命、攻击、经验、基础捕获率；可以指定沿用某怪，或由代理给平衡草案再确认，不从美术体型猜数值 |
| 捕获奖励 | 是否可捕获、时机、费用、掉落及数量；击败与捕获分别给什么；首捕特殊规则和通用失败保底有无例外；奖励去向 |
| 持久化 | 同趟跨图是否复活/回血，下一趟或冷却刷新；退出后攻击阶段、付费捕获与奖励如何恢复 |
| 联动 | 剧情保护、与普通怪并行战斗、采集、任务/料理解锁；没有联动明确记无 |

怪物素材提供或批准制作：主体参考、方向动作、特殊攻击/弹道/预警效果、战斗结果图或指定复用帧、掉落图标。每种填写：

```text
怪物名与素材来源：
地图内相对角色体型：
动作：待机 / 移动 / 攻击 / 倒地 / 特殊动作（按行为增减）
方向、帧数、行序、循环/非循环、播放节奏：
单格/整图尺寸、透明安全边距、脚底/水面锚点、阴影：
特效、结果图、物品图标：复用路径或待制作
交付：原稿、实际提示词（若生成）、生产图集、切图清单、动作拼图、循环预览
```

行列、帧数和锚点可由代理按加载器提案，无需用户手填代码参数。部分现有怪物采用右下、左下、右上、左上四行，必须核对素材契约；四帧、128/192像素单格并非通用要求。原地循环不等于完整奔跑/攻击动画。裁切检查肢体完整、朝向、同屏比例、逐帧脚底阴影；不能独立拉伸每帧造成体型跳变。

## 按需追加

| 功能 | 确认与材料 |
| --- | --- |
| 采集/宝箱 | 名称、位置、交互距离、产物数量、触发手段；永久一次/每趟/每日、时间来源；保存失败、放弃探索、重复命中；道具图与图标 |
| 特殊采矿 | 哪种元素普攻或技能有效，判断发射者还是队伍，多弹命中怎么算，耗尽视觉；不替新矿默认盐晶规则 |
| 剧情任务 | 人物/头像/动作、逐段对白选项、准确触发节点、任务类型和真实完成事件；未定子任务留空列表 |
| 料理经营 | 原料目录、配方、解锁证据、订单/探索用途、星级效果、入库链；仅新增食材不自动设计新菜 |
| 音效环境 | 动作声音/镜头反馈、素材来源、音量和暂停方式；缺素材列缺口，不把无声版称为完整音效交付 |

## 给执行者的最终资料

```text
目标与独立可演示流程：
范围 / 排除项 / 目标工作区：

未决问题（影响哪一步）：
材料（用途、来源/路径、规格、提供人、状态）：
复用对象及已核对规则：
区域连接与点位标注：
拟修改文件 / 必须保留的用户改动：
票据、依赖、Git基线、预算：按根目录AGENTS.md填写
验收场景、实际操作、期望结果、证据路径：
```

正例：有底图但无攻击方案，列攻击决策与动作缺口，继续授权的底图分析。反例：自行复制岩鬃兽咆哮数值和首捕规则，宣称新地图需求齐全。
