# 统一编辑器参数与训练接口

## 2026-11-09统一入口约定（当前）

本批追加完整面板：public/editor-tuning.json登记22组145项，144项可调，1项银鳞鱼旧脱战字段未消费而禁用；十怪基础攻击值另列。分组以base.<怪物>表示基础属性，effect.<招式或受击类型>表示动作/命中/受击，rock.lunge、rock.roar、rock.combo、eel.skill、frog.skill表示各专属技能。每项记录中文名、单位、代码默认值、上下界、步长和connected（是否接入可调消费者）；未开放字段不得进入覆盖。步长必须容纳原默认值，不能因滑块步长让现有合法默认值成为无效输入。

runtimeTuning为父页面的分组候选覆盖，随重开传入隔离editor_tuning.gd。只接受清单内已开放的有限数值；卡肉须为整数。初始化时设置真实属性表和阶段时间，显示按同一时长/范围读取；没有覆盖时仍用既有游戏数据或代码默认值，不改生产文件。editorTrainingStatus.tuning_values是已应用覆盖，tuning_reads是本进程实际发生的数值读取记录，tuning_error是校验错误；读过某字段只证明该消费者读取，不证明所有组合的动作、平衡或视觉均已验收。

导出候选的tuning字段保存这些分组覆盖；无此字段的旧候选按空覆盖兼容。显式tuning覆盖优先于旧角色/银鳞鱼字段，界面同步两者的公共草稿以避免保存对象错位。完整候选保存本机使用独立浏览器存储键maze-unified-training-v1，不删除旧键；加载会完整校验后重开隔离训练，不写正式文件。正式保存接口仍只承接原数据类型，新增144项不因此自动获准进入正式游戏。

editorGeneration为父页面当前场景编号，每次重开立即递增并清空旧就绪/命令；Godot从自身URL读取不可变编号。旧实例不消费新编号命令，页面不以旧编号回执启用按钮或完成加载验收。编号只属于本次页面内的训练实例，不是存档版本或游戏参数版本。验证重置必须等待编号匹配的新引擎，不只检查旧ready。

唯一长期入口为8777。服务直接读取output/combat-feel-playground/preview.html，public/editor.html不再持有第二份界面。本地文件方式打开preview.html会跳转8777；服务没运行时不会降级为旧JS模拟。旧模拟原件保留为preview-legacy-20261109.html，仅供历史核对，不作为验收入口。

训练候选指只进入隔离Godot进程、不改正式参数及存档的一组设置。当前十怪共用同一候选包，专属技能使用原状态机；按钮只设置前摇起点，不制造命中、不绕过真实距离、朝向、地形和保护规则。它不等于全技能参数均已开放。正式数据来源及保存边界以README最新段为准；下方三怪旧格式仅是兼容历史。

接口机器字段：editorTraining（训练开关）包含ai（主动起招）、infinite（防致死并在战斗步恢复双方生命）、bounds（范围及占位显示），默认真、真、假；editorCommands（训练命令队列）依次消费带id（序号）、action（动作）、value（参数）的命令，当前支持start开始、pause暂停切换、step暂停时推进0.016秒、weapon选择0/1/2槽、attack角色攻击、enemy_attack怪物技能和lock锁定切换。editorTrainingStatus（只读回执）含ack最近接收序号、error错误说明、elapsed真实战斗秒数及实际参数。暂停冻结战斗时钟，单步不解除暂停；未知命令、技能或非法起点保持原状态并报告，不把接收成功当命中成功。重开丢弃旧命令队列。

新导出格式type为maze-unified-training（统一训练候选）、version为1：selected_monster为十怪类型之一；training为上述三项开关；monsters为十怪基础攻击数据；player为三招共用卡肉；fish为银鳞鱼专属字段。runtime只记录导出来源，导入不加载其中路径；applied_parameters只记录导出时的实际消费值，不作为导入真源。攻击值0至100整数、卡肉0至200毫秒整数，银鳞鱼字段依schema.json校验。导入先完整校验再设置草稿并重开隔离训练；错误时原候选保留。导出包含当前草稿，实际运行参数另列，二者不混称已应用。

专属技能标识：slime的melee近战与spit吐弹，silverfish的rush蓄力冲撞，thunder_eel的electric蓄电放电，wind_frog的water水枪与slam跳跃砸击，rockmane的lunge单冲、roar咆哮、combo四连，其余怪物melee近战。主动攻击关闭后不自行开始追击或新攻击，已开始的前摇、释放、离体弹丸及恢复继续结束；手动攻击仍经过原状态消费者。无限生命只限隔离训练，不取消受击、击飞或眩晕，也不解除怪物保护。

范围叠加当前使用咆哮/放电/砸击共享范围函数，以及分水庭与岩鬃兽已有脚底占位。其他怪物没有接入叠加图形时明确显示缺口，不绘制假占位。形状参考不替代阶段、朝向与遮挡判伤。更换状态机、参数消费者、地图碰撞、页面源路径或导入格式后，重跑check-unified-editor.cjs相应检查；不得沿用旧三怪页面测试证明十怪接通。

## 以下为旧三怪格式的历史约定

## 用途与范围

本文件与public/profile-format.js共同说明本编辑器version=4的输出。范围是分水庭银鳞鱼、电鳗、巨蛙三类；场景仍只生成一个选中怪物。同类出生点不是独立类型。本轮未接正式游戏文件读取。

## 保存、应用与发布

调整值首先进入当前怪物的内存草稿。切换怪物保留内存草稿并将新选中怪物的草稿应用到重开的独立场景；关闭页面前必须保存。应用候选只改变当前编辑器，不等于保存。保存当前怪物把该怪全部参数写入本入口浏览器存储，不动其他怪物。发布只读取已保存集合，不包含未保存修改；未单独保存的怪物保留默认/迁移值，saved_at为null，不冒充用户已调好。

固定输出是本目录parameters/latest.json，由用户首次成功发布时创建；每次成功发布替换该文件，并在parameters/history保留时间标记版本。失败不清空上一个latest。服务仅监听本机8777，正式游戏不读此入口。导出下载的是同一已保存集合；导入先校验再进入三怪草稿，不立即覆盖浏览器保存值或发布文件。

## 字段

| 字段 | 中文含义与约束 |
| --- | --- |
| version | 集合格式版本，固定4 |
| baseline | 数值适用游戏基准，当前20261106-K-eel-hurt |
| runtime_revision | 编辑器实现版本，20261106-editor-profiles-K-hurt |
| units | 单位标识world_offsets_percent_sizes_milliseconds：偏移为世界单位，尺寸及倍率为百分比，时间为毫秒，angle为角度，opacity为百分比 |
| selected_enemy | 最近保存/导出时选择的怪物，不是发布集合的筛选条件 |
| profiles | 怪物参数集合，必须有fish、eel、frog三个键，不以中文名或实例出生点作键 |
| profiles.<怪物>.effects | 沿原version=3完整招式字段；保存完整七类，界面仅开放选中怪物相关受击和三种玩家攻击 |
| saved_at | 当前怪物最近明确保存时间；未保存为null |
| published_at | 服务端成功发布时间；下载但未发布可为null |

七类effects键：hero为锅铲、yaya为芽芽、tieshan为旋斧、fish为鱼冲撞、electric为电击、water为水枪、slam为落地砸击。具体每招允许字段、默认值、最小最大值以schema.json为准。每个怪物保存完整场景参数：hero/yaya/tieshan是玩家对该怪物调试时所用参数，不应在未来正式接入时无条件覆盖其他怪物场景。当前怪物没有的攻击不会因数据存在就被创建。

## 兼容性与失败行为

既有G/I版version=3同语义数值可迁移；启动时旧共享草稿复制到三类，旧存储键不删除。早期本批I基准version=4可迁入K，但必须三怪基准一致、运行版本匹配、字段齐全且数值在界内。版本1/2继续沿原显式字段映射，无法换算的字段列为未应用，不猜单位。

坏JSON、缺怪、未知字段、越界或不支持版本拒绝导入/发布，保留原草稿和已发布文件。保存失败不会宣称成功。回退时手工导入history中的旧版本，检查后逐怪保存，再发布为新的latest；不会直接自动回滚游戏。

## 当前实现边界与复验

三向受击和巨蛙落地消费者来自主会话已冻结K输入；编辑器参数适配保留效果长于硬直时正常恢复角色的行为。源码冻结输入位置见prepare.cjs；不复制继续变化中的生产主区。正式游戏读取和全项目其他地图怪物不在本轮范围。改变字段单位、怪物键、基准或消费者后需重新验证导入往返、怪物间隔离和真实参数生效；不能只验证JSON格式。

验证入口：test-profiles.cjs、check-profiles.cjs、check-arena.cjs及check-directions.ps1。浏览器检查使用隔离发布目录，不把测试参数当用户正式最新版。
