# 分水庭回水冒汗表现

## 定义与边界

用户在绘制会话确认“明显慌张”的三怪预览并授权接入。回水冒汗是实际回水过程的纯显示反馈，不是新战斗阶段、恐惧状态、加速或存档字段。采用现有角色图及临时程序汗滴，不代表已经生成正式素材。仅普通分水庭；其他地图、特殊试玩和剧情对练不启用。

银鳞鱼、雷鳗仅真实 returning（回水）阶段冒汗；forming（完整入水后凝膜）允许不超过0.6秒的消散尾段，不把岸停、预警、放电或普通巡游当作回水。入水条件沿用当前身体圆完整入水判定，不以中心点、预览假岸线或固定时间代替。

巨蛙目前起落点必须在水中，只有腾空可以越岸。因此只在 mode 为 return（返回）且实际腾空越出完整水域时出现汗滴，保持到这次落水再消散；不能在普通追击跳跃、水中待机或全水域归位时冒汗。不会为了表现而增加岸上落点、修改跳跃周期或新增逃跑规则。

## 显示不变量

- 最多4滴，550毫秒周期，单滴约396毫秒活跃，沿头部侧上方散出渐隐。原预览半径5.7是预览屏幕像素，按角色基础显示宽度换算，不能直接当世界单位。用户于2026-11-03确认巨蛙身体的额外1.4倍不再连带放大汗滴；头部锚点仍根据实际身体矩形定位，鱼鳗尺寸和全部节奏不变。
- 鱼鳗回水动作可沿用现有素材的120毫秒示意节奏，只有回水有效期间采用；巨蛙保持原动作周期及当前候选体型，不默认替换新旧方向素材。
- 完整入水后0.6秒内消失；不再回水且不是合法收尾、死亡、捕获、隐藏、场景释放时清理。沿既有暂停和局部命中停顿冻结显示时钟。
- 不改速度、路径、碰撞、阶段时长、伤害、保护膜规则或锁定规则，不写入存档。

正例：鱼搁浅结束后沿真实路线返回浅水，回水时冒汗、凝膜时短促消散。反例：雷鳗蓄电冒汗，或巨蛙仍在水中回出生点就被当成离岸回水。

## 验收与修正

从真实场景验证自然岸水过程、巨蛙返回越岸、暂停/恢复、结束清理、原攻击和锁定共存，主会话亲看当前截图。未出现真实巨蛙越岸入口时明确记录依赖，不通过增加玩法伪造通过。预览、素材或地形规则变化后重核对应关系。程序接入问题由主会话修正，外观及新图由用户与绘制会话对齐。
