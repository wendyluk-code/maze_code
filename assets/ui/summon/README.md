# 召唤页批准稿图层

布局使用批准稿1672×941坐标，再映射到项目1280×720设计画布，由页面统一等比适配。主视觉不压缩。按用户最新要求，栅栏保持原位，姓名改成角色头部附近的原生竖排姓名及浅色圆弧底板，按钮和价格使用游戏字体，在栅栏上方按原生字体高度保留间距。

- `key_visual.png`：三人及光效的透明整体切图。角色颜色、姿态与尺寸来自批准稿原像素；通过无内容底板解混背景，另用生成的透明轮廓参考保护浅色皮肤与衣服。不能恢复旧版“外围柔化但保留矩形木板背景”的裁切。
- `panel_backplate.png`：仅玻璃范围内的底板。空白处保留批准稿纹理，独立内容图层区域使用生成的无内容底板；页眉线保留批准稿位置。
- `heading.png`：历史标题透明层，当前仅通过 AtlasTexture（纹理区域）显示左侧叶饰，标题文字不再显示；原横线纹理补齐标题空位及主视觉后方空段。`name_*.png` 为历史姓名及叶饰切层，当前不再使用；姓名直接由原生 `Label` 竖排显示，配浅米色圆弧底板及细边框，无花纹或连接线。
- `*_button.png` 与 `*_button_disabled.png`：历史切片，当前按钮不再加载；使用原生圆弧样式及28号游戏字体，禁用态为暖灰底与灰棕边框。
- `single_price.png`、`ten_original_price.png`、`ten_price.png`：历史切片，当前价格不再加载；使用18号游戏字体，富文本原价划线，余额不足直接标红实价。

`layers.json` / `slices.json` 记录来源校验值和图层矩形，格式为 `[x, y, width, height]`。重建使用 `tools/slice_summon_layers.gd`，旧命令 `tools/slice_summon_reference.py` 仅转发到此生成器。需要批准稿和 `output/summon_ui/revision_02/` 下的两张图像处理源文件。

生成辅助图使用内置 imagegen 工具：`clean_plate_source.png` 的提示要求移除人物、光效、标题、姓名、按钮和价格，保留空玻璃纹理与原布局；`extraction_guide.png` 的提示要求将三人及光效提取为透明整体。后者只用于轮廓，不使用生成后的角色RGB，以免改变批准的人物细节。提示词记录见 `output/summon_ui/revision_02/imagegen_prompts.md`。

透明棋盘检查图位于 `output/summon_ui/revision_02/`；最新五分辨率对照、栅栏像素审计和验收记录位于 `output/summon_ui/revision_07/`。检查除轮廓残底外，还须检查脸、手、腿和白色衣物不能被抠空。更换底板、透明轮廓或素材后需重新生成与逐分辨率验收。

本阶段仍只显示界面。单抽1000金币、十连9000金币，分别判断余额；不足时禁用并标红实价。点击只提示“召唤暂未开放”，不扣币、不发卡、不写存档。
