# 冒险者之家角色详情

角色簿点击已收录的芽芽或铁山后打开全屏详情，替代该入口原来的卡牌浏览。原卡牌组件及收藏数据保留。左侧使用按批准稿修复的透明高清角色立绘，显示六颗可变亮暗星与姓名；右侧为属性和技能页签。界面所有文字和数字使用 `SproutTheme.FONT_CN`（游戏中文字体，`assets/ui/zcool_kuail.ttf`），无字皮肤来自 HOME-01 的20张切片。

## 状态与成长

`scripts/characters/character_progression.gd`（角色成长服务）读取 `SaveManager._state` 的 `character_progression_v1` 字段。每个角色记录 `level`（等级1—30）、`exp`（本级经验）、`rank`（抽卡阶位1—6）、`breakthroughs`（已完成等级突破次数0—5）。未收录角色不返回可用记录；旧档缺记录只读派生1级、0经验、1阶、0次突破，不在打开页面时写盘。已有坏记录返回错误，不夹取为高阶位、不扣金币，也不覆盖原值。JSON整数值浮点数合法，布尔、非有限、小数和越界值非法。

抽卡阶位与等级突破互相独立：1阶解锁技能1，6阶解锁六项；金币突破绝不增加阶位，也不立即升级。芽芽初始攻击3，每级加1；恢复百分比初始0.020%，每级增加0.001个百分点。铁山初始攻击4，每级加2；恢复百分比初始0.010%，每级增加0.0005个百分点。恢复显示保留必要精度，例如2级铁山0.0105%。芽芽初始饱腹上限为2，铁山为1，在5、10、15、20、25、30级各增加1，即初始值＋floor(等级/5)。FOOD-01 已接入迷宫外按自身上限计算的实际恢复（含离线），详情显示当前饱腹度／上限；见 [角色饱腹度契约](food_01_satiety.md)。

经验条显示“当前经验 / 本级所需经验”，满级显示“已满级”。候选展示表为500＋100×（等级－1）；该表不是地图经验平衡定稿。后续确定整趟探索怪物组合时修改公共服务函数，不在界面内另写一份表。本票不发放打怪经验。

## 突破交互

5、10、15、20、25级尚未突破时才显示按钮，费用依次100、250、500、900、1500金币。按钮与等级同排且预留固定空间，其他等级、已突破和满级均隐藏；金币不足时可见但禁用。成功后按钮隐藏，当前等级和抽卡阶位保持不变。突破门槛经验必须为0，不储存溢出；非门槛经验必须小于升级所需经验。

突破事务重新核验拥有、状态、门槛、金币、餐厅位置和非重播条件，更新已突破次数与金币后调用原保存入口；失败恢复整个状态快照。重复调用不能再扣费，未知字段与另一角色记录保留。金币变动后按钮自动刷新；保存失败通过现有短暂提示组件说明金币未扣除。

## 页面复用与输入

`scripts/ui/components/character_details_modal.gd`（角色详情组件）继承 `SproutModal`（通用弹窗），复用关闭按钮工厂、主题字体及 `FeedbackToast`（短暂提示）。纸面与页签使用无字完整纹理等比适配，突破底板完整缩放；技能行与进度条使用原生抗锯齿圆角样式，避免切片残留与圆角变形；星星、属性图标、锁和已解锁标识为独立图片。技能描述始终可读，锁定状态降低颜色饱和度并显示解锁阶位。六项在1152×648、1280×720和1920×1080完整可见。

沿用冒险者之家独立画布和餐厅暂停方式。Esc先关闭角色详情并恢复角色格焦点，再次Esc才退出角色簿；返回后继续原餐厅实例，不重建经营现场。
