# 魔物移动动画与朝向修复

目标工作区：`F:\maze_code`。适用于史莱姆、砖壳蜗牛、剑甲虫和石化蜥蜴的地图显示，不修改战斗数值、寻路、出生布局或捕获规则。

## 原因与修改

四种原图均包含四行、每行四帧。旧 `capture_monster.gd` 仅加载出生配置指定的一行；战斗流程只更新节点位置，没有把移动方向传给动画。石化蜥蜴另有固定水平翻转，因此追击和返航都可能出现倒着走。隔离实际迷宫场景复现了26个朝向断言失败，证据在 `output/monster_direction_red`。

现在加载全部16帧，`capture_flow.gd` 在读取战斗状态及推进事务后，将已有速度传给显示节点。四行原图依次为右下、左下、右上、左上；使用对应行，不再固定翻转蜥蜴。停下保留最后朝向，近水平或垂直移动保留次轴方向以避免贴墙微小位移导致抖向。帧周期仍为0.18秒，弹窗暂停仍冻结动画。

所有方向共用同一最大裁切宽度计算缩放，避免转向突然变大变小；蜥蜴和蜗牛的每帧脚底接地点随方向一起切换，阴影继续贴合可见脚底。原图未重制。这些素材是四方向原地循环，修复解决朝向接入，不增加独立奔跑或攻击动画。


复用知识：图集行序是美术契约，不能仅凭出生编号选行，也不能用固定镜像代替运动方向。以后修改图集、速度发布、显示同步、暂停机制或透明裁切时，重跑本专项并重新核对四方向截图。战斗返航专项 `combat_05_flow.gd` 中旧的固定镜像断言已同步改为原方向帧及脚底阴影检查。
