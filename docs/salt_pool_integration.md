用户选定灰绿、暗粉红低矮植被版本，并确认绿色可走区域示意。生产底图为 assets/maps/salt_pool.png，来自 codex-clipboard-e091d5ab-7586-4b10-9e03-80bc0780859a.png，原始尺寸1615×974。标注图只用于审阅，不作为游戏背景或像素碰撞遮罩。

实际世界坐标直接采用底图像素；data/maze/salt_pool_roads.gd 定义外围轮廓和水池、晶簇、植被阻挡多边形，并保留脚底4像素安全半径及分步滑动。左侧接口不新增跨区功能。下方出生点(670,840)，绿色路标(640,900)；分水庭入口与返回点不变。

白盐地50%速度、黄色道路100%速度、冲刺倍率、脚印生成及4秒消退继续使用原实现，未修改 maze_player.gd 或 salt_ground_effects.gd。周期白蒙层已由既有修复移除，本次不恢复。小地图与展开地图继续复用 maze_map/maze_map_view，投影读取 Terrain.SIZE 与共用地图坐标尺寸，人物与底图使用同一归一化坐标。

旧存档坐标仍可走时保留，落水或落入阻挡时复用 SaveManager.maze_exploration_state 的入口安全点回退，不迁移经营或任务状态。

验证：tools/tests/salt_pool_flow.tscn 在目标工作区双分辨率1152×648、1280×720运行127项检查零失败，包含往返、取消、保存失败回滚、速度、脚印、七处地图锚点、真实输入岸边阻挡、读档及结算。截图与报告在 output/salt_map_refresh/flow。4像素网格连通检查18870个可走采样点全部连通；仅证明该采样精度，不代表每个边界像素人工巡检。原图与旧地形备份保留在 output/salt_map_refresh。

当前验收限制：运行期间正式“冒险4”存档持续变化，外部游戏仍在运行；测试报告明确使用 output/salt_map_refresh/flow/profile 下隔离存档，但运行器的正式存档指纹保护未通过，因此最终验收尚未完成。导入和启动无项目错误，系统证书及引擎编辑器设置目录权限告警独立记录。关闭外部游戏后复验存档保护。

可复用结论：更换地图必须同时校准地形尺寸、岸线、道路速度区域、出生/路标与小地图投影；不能只替换纹理。再次换图、变更脚底半径或投影算法时重跑本页验收。
