## 可复用知识与复查条件

锁印是当前探索中单个目标的短时状态，不属于拥有角色或编队预览状态。直接攻击新增入口必须调用 `direct_damage`；间接伤害继续调用 `damage`。正例：锅铲/旋斧消费；反例：水域雷链不消费。新增主动路径、变更攻击归因、星级配置、探索重入或宝箱事务时，重跑本专项并补对应真实路径断言。

Windows 的测试隔离不能仅依赖进程环境变量；独立项目名加实际 `user://` 路径断言是本次验证过的两层措施。引擎版本、项目自定义用户目录设置或运行器发生变化后重新核验。禁止把本专项目录当作正式存档迁移输入。
