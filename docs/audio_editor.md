# Godot 音效管理面板

## 使用

在 `F:\maze_code` 的 Godot 编辑器底部打开 **音效管理**，也可使用 **项目 → 工具 → 打开音效管理**。若编辑器在安装插件前就已打开，重新打开项目；首次接入后也需重新运行游戏一次。

1. 按中文用途、文件名或脚本路径搜索；可筛选音乐、音效、对白，以及使用状态。
2. 选中条目，点击“试听”或双击列表。可停止、循环试听；右侧显示用途、素材路径和调用文件，可打开源码。
3. 拖动滑条或输入分贝。数值越小声音越轻，0 dB 表示原始音量。总音量和分类音量是额外增益，与单项数值相加；右侧显示最终音量。
4. 默认勾选“实时同步游戏”。未保存的修改也会在同一项目中运行的游戏里约 0.2 秒内应用，持续声音不重启，短音下一次播放采用新值。
5. 点击“保存到项目”保留设置；重启游戏仍使用它。“撤销未保存”读取上次保存值，“恢复此项默认”恢复所选用途的原始设置。分类恢复默认时设为 0 dB。

关闭实时同步会让游戏恢复已保存设置，面板仍可试听未保存值。关闭/禁用插件会清理临时预览；编辑器异常退出后，预览最长约 3 秒失效。普通收起面板仅停止面板试听，保留实时调音状态。保存与预览失败时会在底部显示错误。

## 覆盖与边界

本次目录包含 53 个用途条目，覆盖 49 个音频文件及一个代码生成的盐晶无效敲击声。相同素材可以有独立用途：接单与正确交付、烹饪完成与捕获成功分别调音。同一个用途有多个触发位置时会列出所有已核对的位置，例如制作完成提示也用于第一章结束。

“仅登记”指已在全局管理器中登记但未发现当前生产播放调用；“未发现引用”指未找到游戏代码直接引用，仅供试听，不因调音新增事件。这些状态来自 2026-11-06 的静态核对，不是对未来代码的自动扫描结论。新增或改变触发点时须同步目录。

面板负责用途说明、试听和音量，不裁剪音频、不改变播放时机或交付队列。保留捕获连续音的循环接缝、失焦停止规则与场景退出清理。面板试听采用独立音频流副本，不修改素材的导入和循环设置。

实时同步用于编辑器直接运行的本项目，不远程控制已发布游戏。导出游戏在启动时读取已保存配置；当前导出设置包含 `*.json`，因此音量配置随包交付。本轮未执行完整 Web 导出验收。

## 接入与维护

- `addons/audio_mixer/`：编辑器底部面板及菜单入口，采用 Godot 编辑器原生控件和主题，不向游戏场景添加调音界面。
- `scripts/audio/audio_catalog.gd`：中文用途、默认音量、素材、分类及调用文件目录，也是盐晶声音的共用生成入口。
- `scripts/audio/audio_mix.gd`：音量配置读取、校验、原子保存与播放器绑定。损坏配置保留上次有效值，不写入玩家存档。
- `data/audio/mix.json`：保存的用途与分类音量覆盖值；空字典表示沿用当前默认混音。交付时保持全部原音量。
- `.godot/audio_mix_preview.json`：临时预览，带会话标识与有效期，不随游戏导出。
- `GameAudio.bind_volume(player, cue)`：将现有播放器绑定到用途，只更新音量，不调用播放或停止；全局播放器、开始界面、对白、烹饪、倒水、捕获过程与盐晶已接入。

新增声音时先登记目录，再在播放器创建后绑定用途。例如接单与交付共用同一个 WAV 文件，应各用自己的用途标识；不能只按素材路径调音，否则会破坏独立控制。已有 `GameAudio` 音量常量保留兼容，最终有效设置以目录默认值和保存覆盖值为准。

## 验收记录

验收全部在目标工作区 `F:\maze_code` 完成，游戏流程使用隔离存档并核对正式存档 JSON 指纹。证据目录为 `output/audio_editor/`。

- `final_flow/report.json`：219 项面板搜索、实际鼠标滑条输入、49 个素材加载、用途独立调音、分类叠加、预览开关、保存/撤销/恢复默认、损坏与过期配置、循环试听、真实混音输出、场景播放器、真实 E 交付与战斗捕获反馈。
- `editor_panel.png`、`plugin_live.log`：实际编辑器加载并显示面板；独立游戏进程接收 -27 dB 预览的结果及画面位于 `editor_live/`。
- `restart/`：新游戏进程读取磁盘配置，接单音及分类叠加得到 -25 dB。
- `capture/`：49 项捕获音时序、连续 J、循环与停止回归。
- `character/`：346 项餐厅及各迷宫脚步、冲刺、攻击回归。
- `cooking_r2/`：11 项真实 E 打开料理台、开火、播放中调音、完成与输入恢复检查。
- `startup/`：目标主场景无头启动 5 帧；`editor_final.log` 记录正常编辑器导入检查。

实际混音采样验证降低 12 dB 后峰值约为原来的四分之一，证明输出增益生效；不将数值检查表述为主观听感评审。

首次面板脚本检查修正了与原生 Panel 同名的标识符；流程首轮失败源于旧夹具未标记甘露教学完成，已按现行交付夹具补齐并复验。烹饪首轮直接关闭面板仍保留教程输入锁，复验改用真实结果确认流程后通过。各失败日志保留，不作为最终验收证据。

环境仍有系统证书读取告警、历史输出目录 UID（资源唯一标识）重复/缺失素材及 NUL（空字符）文本告警。自定义编辑器验收脚本退出时另有扫描中断和渲染资源释放告警，功能检查通过不代表编辑器全量日志无告警。桌面捕获工具两次超时，界面证据使用 Godot 实际渲染截图。

稳定知识：音量必须按用途绑定，不能按共享素材路径覆盖；跨进程预览必须有失效机制，并与项目持久配置分开。更改播放器创建位置、用途目录、配置格式、音频触发时序或导出过滤条件后，重新执行上述对应检查。
