# 序章动态分镜时间表 v3

本版在 v2 的推拉、横移和转场基础上，为每个分镜增加至少一项画面内动态。动态均为可逆的 2D 合成层，不改变已确认关键帧、角色形象或 NPC 黑影规则。

| 分镜 | 画面内动态 | 叙事作用 |
| --- | --- | --- |
| 古老王国 | 太阳沿天空弧线移动，晨光—正午—暮色，云与河面高光缓动 | 用时间流逝压缩王国兴衰的历史感 |
| 国王画像 | 火把暖光从左向右扫过，画像边缘短暂反光 | 对应“火光依次照亮” |
| 三种传言 | 血脉线、金色流光和泉水区域出现循环光点 | 让三种传说各自有视觉生命 |
| 王国泯灭 | 低机位轻震、落尘与碎石运动 | 强化城堡正在失稳的瞬间 |
| 王陵发现 | 冷色尘埃下落、镜头持续深入空棺 | 由地震余波过渡到寂静 |
| 石碑 | 符文中心周期性亮起，四角压暗 | 将碑文变成叙事锚点 |
| 永生之泉 | 蓝色微粒在迷宫深处漂移 | 诱导冒险者继续深入 |
| 迷宫综合症 | 青灰色呼吸脉冲与稀疏冷雾 | 表现体力和希望都在消退 |
| 魔物肉奏效 | 金色恢复环与亮度回升 | 形成“异常有效”的视觉转折 |
| 主角料理 | 火光呼吸、锅上蒸汽上升 | 从悬疑切入温暖的料理段 |
| 递给芽芽 | 碗与锅的蒸汽持续上升 | 让对白中的“也能吃吗”更有生活感 |
| 沸腾转心跳 | 暗红色心跳脉冲逐渐压黑 | 声画同步进入深层异常 |
| 深层异常 | 水面同心波纹、根须色光脉动 | 只展示局部生命组织，不揭示完整循环 |
| 记忆碎裂 | 轻微镜头震颤、碎片闪亮与白光脉冲 | 表现触碰未知物后的记忆崩解 |
| 标题与餐厅 | 标题沉黑后，餐厅叶影和暖光点缓慢出现 | 把心跳自然交给教程场景 |
