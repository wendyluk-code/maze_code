# 问题分流标签

工程技能使用下表，将五种标准分流角色映射到本项目的实际标签。

| 标准角色 | 实际标签 | 中文含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待维护者评估与分流 |
| `needs-info` | `needs-info` | 等待补充必要信息 |
| `ready-for-agent` | `ready-for-agent` | 描述与输入已具备，可交代理执行 |
| `ready-for-human` | `ready-for-human` | 需要人工处理 |
| `wontfix` | `wontfix` | 已决定不予处理 |

技能提到分流角色时，使用对应的实际标签，不另建同义标签。
调整名称时更新本表。

`ready-for-agent` 只表示分流结果，不代表已获写入或派单授权；
开始执行仍须满足 AGENTS.md 的要求。

本文件登记标签映射，不表示远端标签已经创建或验证。
