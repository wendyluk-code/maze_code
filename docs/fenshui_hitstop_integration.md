## 2. 原问题与影响

用户要的是命中“卡一下，再挥过去”，不是继续加图片或延长白闪。已认可的弧光、角色动作和水膜保留；本轮没有生图、修改原图、增加震屏或音效。

## 3. 原因

原action_left（动作剩余秒数）同时决定旋斧动画与行动结束，怪物的实际击退、受击时间和白闪由探索保存事务推进。只冻结显示会让后台先走完击退，因此采用用户已确认的局部时间线延长，不在恢复后加速追赶。

## 4. 解决方式

axe_hitstop.gd维护内存局部时钟。正常分水庭由capture_flow.gd安装50／70配置；隔离入口仍能明确覆盖为对照档位，旧fs01_trial引鱼借电特殊试玩不自动安装。事务用时钟副本推进，成功后采用；保存失败不消耗或错误触发停顿，不新增存档字段。真实旋斧命中收集目标，同挥砍只触发一次，多个目标并行。

只延后当前挥斧和本次目标的动作、击退与白闪，然后原速继续；扣血时刻、攻击冷却、玩家移动、场景时间和未命中对象继续。不改66像素周身判定，不新增无敌或停顿后的眩晕。

capture_flow.gd仅在安装时钟的旋斧动作中使用10毫秒步进；弧光读原动作状态，怪物显示同步停顿。致命一击后，原倒地等待仍消耗剩余停顿，避免互相锁死。专用F5／F6仅属于隔离工具，优先处理，不被捕获对话吃掉。工具属于整个隔离试玩会话：重载后重新绑定新地图；离开对照时常驻说明并提供“返回卡肉对照”，不为其他地图的怪物回血；关闭试玩时释放。正常场景没有这些控件，其他地图不自动安装时钟。
