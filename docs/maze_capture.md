# 首区战力与捕获探索

本版接入 `scenes/maze_entry.tscn`，保留原道路、宝箱、挖掘、爷爷任务和地图。移除迷宫中的御风／萨莉亚演出及史莱姆卡牌战斗入口；旧战斗模块仍供其他入口使用。

## 规则与存档

出发时从角色成长记录读取当前出战成员的等级、阶位、基础攻击和饱腹上限，冻结为本趟快照。基础战力应用铁山同系队友增益；本趟总战力为该值加已吸收战力。只有严格大于魔物战力才击败。战力相等或不足只挡路，不扣资源、不计算生命值。

击败时立即全额吸收战力并保存，随后胜利弹窗的“是”只进入捕获详情。详情选择否不消耗饱腹度；详情选择是开始捕获，无论成败消耗1。捕获不会扣战力，结果不影响吸收。每只魔物在本趟最多吸收、捕获一次。失败或放弃后不会刷新。

首次探索的第一只被击败史莱姆确认捕获后必定成功，即使完全不按 J 或未达标，产出史莱姆核与史莱姆凝胶各1份；芽芽复制可以增加整组数量。该资格在击败时用掉，放弃捕获不转移给下一只。旧档已开始第二章的玩家不补发首次资格。

`capture_run_v1` 保存本趟成员快照、饱腹度、吸收量、每只怪状态、随机值、待选择对象和临时材料。随机值进场生成后持久化，读档不重掷；待选择捕获在恢复后重新显示。事务保存失败恢复完整状态，不重复付费或领材料。JSON读回的整数浮点表示按数值核验。

左侧出口把临时捕获材料一次性加入餐厅库存；入口主动放弃清空本趟捕获物。两种返回都会清零吸收量。永久宝箱、挖掘及既有任务奖励仍按原规则处理，不纳入捕获暂存袋。HUD（屏幕常驻信息）显示总战力、公共饱腹度和临时材料总数。迷宫背包在进入迷宫时直接解锁，只读展示本趟 `capture_run_v1.bag`，标题为“本趟暂存食材”；它不读取餐厅库存、不修改永久仓库。出口结算时临时袋转入 `warehouse_stock`（餐厅仓库），主动放弃时清空。

进场调用 `SaveManager.record_maze_location()`，沿用体力任务的扣费事务；恢复当前探索不重复扣体力，详见 [体力说明](stamina_01.md)。本票不发放角色经验或实现抽卡；成长等级、阶位只读取现有角色记录。FOOD-01 新探索饱腹度取成员当前余额之和，按顺序轮流由一名足额成员承担每次1点，离场不返还，迷宫外按个人效率恢复；详见 [角色饱腹度契约](food_01_satiety.md)。

芽芽按1至6阶累积执行15%复制、基础提高到20%、克制额外10个百分点、基础提高到25%、触发复制后20%概率再复制一份、每趟前三次成功克制捕获必复制。铁山每名同系队友增益按阶位为3／4／4／5／5／7%，三阶起至少两名额外3%，五阶起三名额外4%，本人不计队友。

`capture_dialog.gd` 复用 SproutModal（通用弹窗），内容面板沿水平轴压缩、展开实现左右翻转；遮罩持续拦截地图操作。零饱腹按钮变灰但接收点击以显示准确短暂提示。奖励复用 LootModal（获得物品弹窗），退出复用 DestinationConfirmation（通行确认），错误提示复用 FeedbackToast（短暂提示）。

史莱姆核保留旧存档标识 slime_shell，显示名已纠正；对应独立图标待用户确认生图提示词后接入。获得食材标题不再附加“出口带回”，出口结算机制保持。奖励窗口对金币与所有捕获食材按可见轮廓统一缩放到43像素显示区域，避免透明留白使图标偏小。
