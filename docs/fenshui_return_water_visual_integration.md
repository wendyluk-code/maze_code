## 4. 接入方式

capture_monster.gd 仅增量创建、同步、推进及清理 return_water_visual.gd（回水显示组件）。组件按真实身体图格与朝向贴合头部侧上方；最多4滴、550毫秒周期，按角色基础宽度换算尺寸。2026-11-03用户确认：巨蛙额外1.4倍身体不再连带放大汗滴，锚点仍跟随实际身体矩形；鱼鳗尺寸、形状、颜色与节奏不变。鱼鳗回水采用120毫秒帧节奏，其他阶段和巨蛙周期不改。完整入水后最多0.6秒消散。

不改原角色图、保护膜图、速度、路线、碰撞、伤害、攻击规则、存档或其他地图。暂停和局部命中停顿沿用原时钟；隐藏清理响应可见性事件，不能等待被暂停的显示时钟。
