# 本地隐藏调试工具

使用：在游戏窗口内依次输入78789（相邻数字间隔不超过3秒，支持主键区和数字小键盘），即可打开。没有常驻菜单入口。按Esc或点击关闭后可再次呼出。

## 资源与生命

“资源与生命”页保留增加金币、增加星尘、增加队伍饱腹度、补满队伍饱腹度，数量范围为1—1000000。新增“回满生命”按钮；探索时直接按Ctrl+0也能使用，支持主键区及数字小键盘，长按产生的重复事件不会连续触发。

回血只把当前探索队伍的共享生命恢复到本趟上限，不消耗道具、不改变队伍、携物和其他战斗字段。没有有效探索时提示原因。打开面板和正常地图操作时都可使用；关闭面板后原血条自动刷新。

## 地图跳转

“地图跳转”页提供枯水渠、分水庭、盐池、青苔池、守水人小屋。各图可选正常入口；分水庭另有鱼鳗观察点和巨蛙附近，落点按当前地形检查可走性。

| 操作 | 实际行为 |
| --- | --- |
| 跳转所选地图 | 按地图、落点下拉框进入；普通切图保留当前队伍、生命、携物及已保存的怪物结果，取消追击和瞬时攻击。 |
| 重载当前地图（保留进度） | 重建当前场景，保留本趟状态及保存的位置。 |
| 重新开始本趟试玩 | 在当前地图正常入口开启新一趟试玩，恢复新一趟生命、重置携物及怪物；跳图下拉框不影响当前地图。尚未进入迷宫时按下拉框选择创建试玩。 |
| 退出试玩，返回原进度 | 恢复第一次调试跳图前的完整存档数据、存档路径及待入场队伍，再打开原进度对应场景。 |

首次跳图会把当前数据复制到独立文件`user://debug-map-trial.json`，后续试玩操作只保存到这份副本；返回所需的原始状态保存在本次游戏进程内。重开试玩不清除原档。这里只隔离调试跳图后的操作；在普通存档上直接使用资源或回血功能，仍会保存到当前加载的普通存档。

跳图沿用已有第一章完成和探索队伍检查，不自动跳过剧情。当前有未完成捕获或奖励操作时拒绝跳图；未知地图、不可走落点或试玩保存失败时保留当前数据和存档路径。

## 运行版本与界面

面板显示运行目录、启动时间、代码摘要、当前地图及当前存档文件。代码摘要在启动时读取相关调试和战斗脚本的内容生成，用于区别游戏实例，不代表仓库全部文件的版本，也不证明已合入其他工作树。

切图、重载和重开试玩都不会更新代码。修改代码后需要重新启动对应目录的游戏；已运行的旧窗口不能据此视为最新版。

仅Godot编辑器运行及调试构建启用；正式发布构建由OS.is_debug_build关闭入口和修改接口。数字序列只是隐藏入口，不是身份验证，不应将调试构建当作正式版分发。

资源和回血修改立即写入当前加载的本地存档。增加饱腹度按输入的全队总量依队伍顺序分配，单人不超过成长后的上限，未出战角色不变；探索中同步capture_run_v1（本趟探索记录）的总量。没有当前队伍时给出提示。重播和序章预览拒绝修改。保存失败恢复完整修改前数据，不迁移、不清空未知字段。

面板为全局Autoload（自动加载）节点LocalDebug，复用SproutTheme主题、SproutButton按钮、sprout_tab_bar标签页、feedback_toast短暂提示和modal_style遮罩。打开时保留原暂停状态、焦点与各节点输入处理开关，临时阻断底层快捷键；关闭后恢复。地图转场复用scene_transition，并保持场景树暂停到转场结束，避免旧场景读取新一趟状态。其他场景沿用原行为，生命、饱腹度、金币、星尘显示沿用既有刷新机制。
