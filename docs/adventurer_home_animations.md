# 冒险者之家角色列表与卡牌浏览

## 表现与边界

餐厅靠近入口后，点击悬浮按钮或按一次E直接进入冒险者之家，无二次确认。返回保留餐厅实例、站位并恢复输入。

主界面使用静态角色列表，不创建移动、待机、招呼或渐隐渐显动画。现有 `SaveManager.departure_state().party`（第一章入队记录）作为芽芽和铁山的收录依据；未收录时显示缺省格。这是当前两人的接入规则，后续独立角色库建立时需替换查询入口，不能把所有未来角色的收藏状态等同于出战队伍。

每次进入默认选中“角色簿”页签，选中字体金色、原尺寸，未选中页签横向缩至88%、纵向98%。页签在页面左侧上下排列、文字横排。页眉左叶枝、右侧同水平长线与末端叶枝、页签点线和叶片、卡片纸纹边角与底部叶枝均使用已确认设计稿切片，不能改回代码近似绘制。已收录角色的姓名带分别保留原稿芽叶、山纹，姓名使用游戏字体动态显示。

列表位于屋檐至栅栏之间，共4列16个正方形格子，首屏1.5行；支持垂直滚动到末行。1280×720设计坐标中滚动窗口为(234,178)、954×340，单格216×216，列间23、行间16。芽芽与铁山使用餐厅对话立绘，裁切窗口为200×168，姓名纸带单独置于下方；缺省格直接显示切片中的问号、“未收录”和叶枝，不可点击。召唤仅显示未开放提示，没有抽取或奖励事务。

半透明面板为(128,108)、1106×480，保留圆角与细亮边。栅栏从实际场景背景沿深色外轮廓逐列抠出透明前景，与背景共用全屏等比居中适配；前景绘制在列表和面板上方，不使用整条地板矩形。详情组件挂在页面所属的独立画布层（主页层号+1），整个全屏暗幕和卡牌都位于主页与前景之上；背景子节点调整绘制顺序也不能越过暗幕。关闭隐藏详情，退出主页一同销毁画布。所有设计坐标随窗口等比缩放。

点击已收录立绘打开现有原图卡牌蒙层；左右拖动、触屏滑动、左右键或按钮浏览手牌，首尾不循环越界。卡牌展示只有暗幕和用户原图，不拼装卡框、标题或效果文字，不加大面板。关闭和翻页复用 SproutModal（通用弹窗）的关闭契约、SproutTheme（局部主题）、SproutButton（按钮）。下层页签、角色格及返回按钮禁用，Tab焦点限制在蒙层，Esc只关卡牌层并恢复角色格焦点。

一屏五列：左侧冻结角色牌，卡牌下方以暖色小名牌标注角色姓名（芽芽、铁山），不显示角色牌数量，不铺整块底色；右侧四列展示当前获得的不同手牌。只有右侧可横向滑动；超过四种才出现翻页箭头和范围计数。相同ID合并，仅手牌在图下显示x数量；数量为0或未拥有不显示，不补空卡。图像按完整纹理等比显示，透明边缘、卡框和文字均保留。关闭按钮隐藏绿色焦点框，仍保留键盘焦点与关闭操作。

当前芽芽首批为角色牌1张、小小掌勺人1张、温火照料2张、战地小厨1张、热锅协作1张；四种手牌占四格，温火照料仅显示一次且标x2。数量依据用户提供 `C:/Users/KSG/Downloads/芽芽卡牌.xlsx` 的“牌张数”列。铁山当前仅有角色原图，不虚构其手牌。

拥有记录在存档 `owned_character_cards_v1`（原图收藏数量表），键为角色/卡牌名称标识、值为非负整数。`SaveManager.owned_character_card_counts()` 返回独立整数快照；已拥有ID与 `home_card_art.gd` 的素材目录取交集，再按角色筛选。新增素材不会自动获得；现有明确空表、零数量、部分拥有记录均原样尊重。旧16张程序卡的 `cards_state()` 和战斗演示牌库不是此页面的拥有来源，其原接口不变。

首次入队事务写入上述已确认首批记录，与入队同一次保存且失败整体回滚。旧档只有缺该字段且角色确实已收录时，在读取阶段兼容一次首批记录；不从不断扩展的素材目录推导，不在读取时写盘。坏数量保留原始值、输出诊断并显示空列表，不重新补牌。JSON读取的整数型浮点数在快照中转成整数。未来抽取/奖励应更新此数量表并沿用原子保存，不能只新增卡图或改战斗手牌。

## 资源与入口

- `scripts/ui/adventurer_home.gd`：页签、16格静态立绘列表、收录状态及背景布局。
- `assets/ui/home_collection/`：9张原稿/背景切片及 `slices.json`（来源坐标与处理说明）。`tools/slice_home_reference.py` 可由 `output/home_reference_slices/approved_reference.png` 复现素材；原稿用于切片，不作为带假按钮的整页背景。
- `scripts/ui/components/home_sign_tab.gd`：左侧伸出的书签页签、横排文字、选中金字和未选中缩放。
- `assets/maps/adventurer_home_collection.png`：内置imagegen去掉固定木牌的背景，原图保留。
- `assets/characters/yaya_portrait.png`、`assets/characters/tieshan/tieshan_portrait.png`：复用餐厅对话立绘。
- `scripts/ui/components/character_card_art_modal.gd`：冻结角色原图、四格手牌滑动、数量和输入隔离。
- `scripts/ui/components/home_card_art.gd`：素材目录、固定首批记录、数量校验与拥有筛选。
- `assets/ui/battle/cards/yaya/`、`assets/ui/party_cards/tieshan.png`：用户既有完整卡牌原图，直接引用且不修改。

旧 home_collection_decor.gd（几何装饰）、home_greeter.gd、home_wanderer.gd、程序卡蒙层 character_cards_modal.gd、动作资源及历史GIF保留，但当前页面不加载、不执行。

角色列表、页签切换和卡牌浏览均不推进任务、不改变库存、不写存档。关闭页面释放列表和蒙层，重入默认“角色簿”并回到列表顶部。

正例：点击芽芽只浏览拥有的芽芽卡牌；关闭卡牌后仍在居酒屋。反例：混入铁山卡牌、列出未拥有牌、Esc一次同时关闭卡牌和冒险者之家。

## 验收与重新检查条件

运行 `tools/tests/home_residents_run.ps1`，现加载 `home_owned_cards_input.gd`。在1152×648和1280×720验证原页面往返、无旧动画节点、默认页签与缩放/金字、4列16格、首屏1.5行、滚轮到末行、缺省格禁用、页签切换、实际拥有子集、5图同屏、角色牌冻结、重复数量、四格溢出鼠标/触屏滑动、键盘与按钮、首尾、空态、焦点隔离、逐层关闭、清理及浏览不写存档；另验证数量保存重读、明确空表、坏数据、旧档迁移幂等与入队保存失败回滚。多于四种手牌使用明确测试样例，不增加正式拥有卡。卡牌横滑触屏用原生输入事件注入，未覆盖实体触摸屏设备。

更换背景、列数、原图比例、拥有记录格式或页面生命周期时重新验收。布局使用同一设计坐标等比缩放；冻结角色在滑动容器之外，滑动上限是手牌种类数减4。不可用整个素材目录代替拥有记录，也不可为旧编号随意匹配新原图。
