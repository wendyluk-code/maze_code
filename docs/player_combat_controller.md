## 职责与接口

| 对象 | 责任与调用 | 不承担的内容 |
| --- | --- | --- |
| PlayerCombatController，scripts/maze/player_combat_controller.gd | maze.player.combat_controller持有；install(flow)安装原攻击显示、受击显示、卡肉和锁定标记；handle_input(event)处理战斗输入；sync(run)清无效目标；cycle()切换有效目标 | 不直接扣血、写存档、修改地形或怪物行为 |
| PlayerCombatRules，scripts/maze/player_combat_rules.gd | REGIONS列出正常五图；enabled(combat)供模拟及场景判断能力 | 不持有第二套状态，不以目标锁定是否开启决定地图碰撞 |
| capture_flow | 保留character_combat_enabled()、target_lock_enabled()、player_recovering()及locked_target_id兼容入口；转发到玩家模块 | 不再独立持有另一份锁定编号 |
| CaptureRun / Combat / TeamAttack | 原攻击及推进事务，成功后返回hit_feedback和player_hurt_feedback，成功才采用内存卡肉时钟 | 显示层不得反向结算伤害 |

Tab首次选可见最近目标，再按原目录循环；Q解除；空格及1至4换招。换招不换锁；锁定只决定当次攻击方向，不扩射程、跟踪或追击。死亡、捕获、回位、不可选、移出视口和离图清理；不写锁定进存档。旧剧情/试玩保留Tab切招。

分水庭脚底占位仍只在原正常分水庭启用，不因其他地图共用锁定或受击而推广。普通怪缺少width配置时使用原48标定的后备值，命中图最终仍按招式固定尺寸，不跟身体体型变化。

| 玩家恢复 | player_hurt_event.gd：physical、电击、水枪600毫秒，slam900毫秒；fish沿SilverfishEditor读取 | 恢复字段内部秒，取消未完成攻击，保留已发弹体、原击退及冷却，不增加无敌 |
