# 首只史莱姆喷射教学

目标工作区：`F:\maze_code`。仅在探索教学尚未结束、且首次喷射尚未完整完成时保护 `slime_1`；随机布局、其他魔物、原有攻击伤害和命中规则不变。已有探索教学为 `done`（完成）的存档不补发强制说明。

## 玩家流程

1. 原攻击教学读完后，锅铲、芽芽与铁山的实际命中统一计数，空挥不计；累计第三次命中后暂停战斗，芽芽说明：“按【Tab键】可以切换不同角色的技能，选择趁手的技能进行攻击吧”。
2. 确认切换说明后，允许首只史莱姆开始喷射；保护期间贴身也能开始，不再受大于42世界像素的下限限制，仍检查道路遮挡和180世界像素上限。前摇直接推进，不再插入格挡说明。
3. 随后推进0.65秒前摇，发出弹丸，再完整推进0.28秒喷射动画。此时才解除最低1点生命保护；弹丸是否命中或已经消失都不参与解除条件。解除保护不会自动扣掉最后1点生命，后续攻击可以正常击败它。

## 保存与恢复

`ch2_guide_01.combat_hits`（第一句后的命中数，最大3）、`seen.05_switch`（切换说明已读）、`seen.05_spit_complete`（喷射完整完成）分别保存。旧档格挡已读键不再参与流程；旧前摇未读状态恢复后继续吐弹。

`combat.slime_lesson`（本趟教学运行状态）由现有探索存档同步。命中、切换说明、喷射完成与战斗事务一起提交；保存失败恢复整个事务，不能提前解除保护。离开场景、读档或暂停不补算教学前摇。死亡或返巢中断喷射不算完成；回到有效战斗后仍需完整喷射。

`team_attack.damage`（统一命中伤害处理）同时供投射物和铁山近战使用，防止某一攻击入口绕过最低生命限制。今后增加伤害入口时应接入同一处理或明确重新审查保护规则。
