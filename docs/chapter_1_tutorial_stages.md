# 第一章《第一顿饭》目标规格与验收蓝图

## 1. 文档状态与章节边界

本文件是第一章“从主角醒来到准备进入迷宫浅层”的权威目标规格。它同时记录当前代码事实、目标行为、状态不变量和后续票据边界。目标描述不代表当前实现已经完成。

本章承接约 4 分钟序章视频，结束于地图、队伍、卡牌和迷宫入口解锁；不在本章进入迷宫。序章内容见 `docs/game_outline.md`。

芽芽与铁山各 8 张初始卡牌的名称、效果、数值和素材由用户后续提供。在材料到位前，不得自行设计、生成占位卡牌或把空卡牌列表视为完成。

- 材料：`岩鬃肉 ×1`、`岩盐 ×1`
- 首次结算：餐厅声望 `+20`

## 3. 第一章状态契约

### 3.1 稳定阶段

实现应保存可恢复的稳定阶段，而不是只保存教程步骤索引：

| 阶段值 | 含义 | 必要状态 |
| --- | --- | --- |
| `not_started` | 尚未开始第一章 | 无首单临时状态 |
| `awakened` | 苏醒对白完成 | 无经营状态 |
| `guest_arrived` | 铁山到达前台 | 首单可被接受 |
| `order_accepted` | 首单已经接受 | 订单需求为盐烤岩鬃肉 1 份 |
| `ingredients_collected` | 已从仓库领取最后一份材料 | 岩鬃肉 1、岩盐 1 |
| `dish_ready` | 料理已经完成 | 材料归零，盐烤岩鬃肉 1 |
| `order_served` | 首单已经交付 | 成品归零、订单完成、声望奖励只结算一次 |
| `ready_to_depart` | 地图与同行决定完成 | 旧盐池地图、队伍、入口与新目标已解锁 |
| `done` | 第一章完成 | `chapter_1_done=true`、`tutorial_done=true` |

字段名是建议的机器表示，具体 schema（数据结构）可在实施票内调整；上述可观察状态和转换顺序不可改变。

### 3.2 经营事务不变量

教程只观察真实经营事务的成功事件并推进，不得自行写入成功 Toast 冒充事务：

`玩家按 E → 经营系统校验 → 原子写入状态 → UI 显示结果 → 教程收到成功事件 → 保存稳定阶段`

必须满足：

1. 前台只能在 `guest_arrived` 接受首单；重复接单不创建第二个订单。
2. 仓库只能为本订单发放一次岩鬃肉与岩盐；乱序、重复或失败操作不改库存。
3. 料理必须校验材料，成功后原子扣除材料并增加一份盐烤岩鬃肉；失败不生成成品。
4. 交付必须校验进行中的订单和匹配成品；成功后只结算一次 `+20` 声望。
5. 正常完成首单后，教程材料与成品均为 0；阶段 7 再次查看仓库必须得到同一真实结果。
6. 所有交互 UI 使用 `docs/ui_component_library.md` 规定的组件库。每张交互票开工前，单独确认按 E 后的动作、界面内容和视觉稿。

### 3.3 完成、跳过、重播与恢复

**正常完成**：按顺序完成真实首单、后续剧情和解锁；首单声望奖励写入一次性结算凭证，重复信号、重进场景或重复 E 不增加奖励。

**跳过**：从任意阶段跳过时，以一次原子操作收敛到 `done`：取消旧镜头、计时器、输入锁、暗幕和临时 NPC；清除教程中间材料与成品；把首单标记为已处理；只在不存在首单结算凭证时补发 `+20`；解锁地图、队伍、卡牌、入口和下一目标；最后写入两个完成标记。重复跳过结果不变。

**重播**：`--replay-tutorial` 可重演对白和操作，但不得修改正式存档、重复发材料、重复增加声望或重复解锁。重播结束恢复进入前的世界状态。

**退出重进**：从最近一个稳定阶段恢复。未完成的镜头、逐字显示、Tween（补间动画）和计时器不持久化；重进时重新建立该阶段唯一流程，不并行恢复旧异步回调。

**旧存档迁移**：

- 只有 `tutorial_done=true`、缺少 `chapter_1_done` 的旧存档继续视为第一章未完成；
- `chapter_1_done=true` 但缺少新版解锁字段的旧存档，在加载时幂等补齐 `done` 的世界状态；
- 迁移以一次性结算凭证判断是否补发 `+20`，不得仅凭字段缺失重复奖励；
- 损坏或类型错误的章节数据回退到最近可证明的一致阶段，并记录可诊断日志。

## 4. 七阶段目标流程

### 阶段 1：苏醒与失忆

主角输入和物理移动全程锁定。对白支持鼠标左键、E、空格和 Enter；文字未显示完时，第一次操作只补全文字，下一次才推进。

1. 芽芽：“……你终于醒了。”
2. 芽芽：“你还记得我吗？”
3. 主角：“……？”
4. 芽芽：“……果然，你又想不起来了。”
5. 芽芽：“没关系。我陪着你，总会想起来的。”

完成后保存稳定阶段 `awakened`。

### 阶段 2：客人入场

镜头演出参数：

- 镜头目标：`(1000, 320)`
- 镜头倍率：`1.35`
- 铁山演出位置：`(1000, 300)`
- 镜头移动时间：`1.1` 秒
- 铁山出现后停留：`0.9` 秒

此阶段必须显示正式铁山 PNG。程序内部可识别角色为铁山，但在他说出“我叫铁山”以前，对话框姓名显示“？？？”。不得继续显示占位剪影或占位气泡来冒充正式角色；场景资源是否重命名不作为玩家行为验收条件。

对白：

1. “？？？”：“哪……哪里……有吃的吗？我……快不行了……”
2. 芽芽：“先不说了，救人要紧。”
3. 芽芽：“你不会连怎么做饭都忘了吧？……没事，跟我来——你以前，也是这么做的。”

镜头在对白期间停留在前台；进入移动教学时用 `0.8` 秒回到玩家，恢复原倍率和移动。完成后保存 `guest_arrived`。

### 阶段 3：前台接单

1. 显示提示：“用 方向键/WASD 走到前台，接下他的订单”。
2. 教程接近判定半径：距前台中心 `120px`；正式交互可用性继续复用全局交互距离函数。
3. 接近后显示：“靠近前台后，按 E 接下订单”。
4. 按 E 后，真实创建并接受唯一首单：`盐烤岩鬃肉 ×1`。
5. UI 显示：“已接单：盐烤岩鬃肉 ×1”，订单区域可继续查询该订单。

只有经营系统返回接单成功后，教程才保存 `order_accepted` 并推进。错误目标、重复 E 和超出范围均不得改变状态。

### 阶段 4：仓库取食材

1. 显示提示：“去仓库拿肉和盐”。
2. 教程接近判定半径：距仓库中心 `150px`。
3. 接近后显示：“靠近仓库，按 E 领取食材”。
4. 按 E 后，仓库真实发放 `岩鬃肉 ×1`、`岩盐 ×1`。
5. UI 显示：“获得：岩鬃肉 ×1、岩盐 ×1”，库存区域同步显示数量。

只有库存事务成功后保存 `ingredients_collected`。这两项是仓库最后的食材，重复领取不能增加库存。

### 阶段 5：制作料理

1. 显示提示：“放上料理台，煮熟它”。
2. 教程接近判定半径：距魔法汤锅中心 `140px`。
3. 接近后显示：“靠近料理台，按 E 制作料理”。
4. 按 E 后校验配方与库存，扣除岩鬃肉 1、岩盐 1，生成 `盐烤岩鬃肉 ×1`。
5. UI 显示：“【盐烤岩鬃肉】 做好了！”，库存同步变为材料 0、成品 1。

只有制作事务成功后保存 `dish_ready`。材料不足、错误配方或重复输入不得产生料理。

### 阶段 6：交单上菜

1. 显示提示：“端过去给他，小心别洒了”。
2. 教程接近判定半径：距前台中心 `120px`。
3. 接近后显示：“靠近前台，按 E 交单上菜”。
4. 按 E 后校验唯一首单与匹配成品，消耗成品，完成订单并结算声望 `+20`。
5. UI 显示：“顾客吃得很满足！ 餐厅声望 +20”。订单变为已完成，声望 HUD 同步刷新。

只有交付事务成功后保存 `order_served`。没有料理、料理不匹配、订单已完成或重复 E 都不得重复结算。

### 阶段 7：准备同行

#### 7A. 料理见效

铁山放下盘子，看着停止颤抖的手。此时对话框仍可显示“？？？”。

> “？？？”：“……缓过来了。”
>
> “？？？”：“这是岩鬃兽的肉？那东西又硬又腥，你居然能做成这样。”
>
> 芽芽：“他以前做得更好。”
>
> 主角：“以前？”
>
> 芽芽：“……嗯。”
>
> “？？？”：“还能再来一份吗？”
>
> 芽芽：“再去仓库看看吧。”

#### 7B. 发现食材耗尽

主角前往仓库并按 E。仓库 UI 必须读取真实库存，显示：

- 没有任何食物
- 岩鬃肉：`0`
- 岩盐：`0`

随后对白：

> 芽芽：“刚才已经是最后一份了。”
>
> 主角：“岩鬃兽在哪里？”
>
> “？？？”：“迷宫浅层，旧盐池附近，我就是从那边回来的。”

铁山取出地图。解锁道具“地图”，只显示第一层地图；旧盐池区域可见，其他区域由迷雾覆盖。地图解锁必须是可查询、可保存的真实状态。

#### 7C. 铁山主动提出同行

铁山扶着桌子站起，拿起武器。

> “？？？”：“我叫铁山，是个冒险者。”
>
> 铁山：“你如果要去，我可以带路。”

从自报姓名后的下一句开始，对话框姓名改为“铁山”。

#### 7D. 芽芽反对并决定同行

> 芽芽：“……不行。”
>
> 芽芽：“你才刚醒，连自己是谁都不记得。”
>
> 主角：“可我还记得怎么做饭，我想继续做下去。”
>
> 主角：“没有食材，就做不了下一顿。”
>
> 芽芽：“……那我也去。”
>
> 芽芽：“谁都不许往深处走。”
>
> 铁山：“说定了。拿够食材就回来。”

#### 7E. 同行角色与卡牌解锁

系统提示：“芽芽、铁山加入探索队伍”。队伍状态真实加入两名角色，不得只显示文字。

随后分别展示：

- 芽芽；定位：辅助；初始卡牌 8 张，依次展示；
- 铁山；定位：守卫；初始卡牌 8 张，依次展示。

卡牌展示和卡组写入阻塞于用户提供 16 张正式卡牌内容与素材。材料到位前，本小节和第一章最终端到端验收保持“未完成”，不得生成替代设计。

#### 7F. 教程结束

完成以下原子收束：

1. 生成目标：“与芽芽、铁山一同进入迷宫浅层”。
2. 芽芽：“等你准备好了，我们再一起去看看。”
3. 迷宫入口发光亮起，但不自动切换场景。
4. 解除玩家锁定，恢复镜头位置和倍率。
5. 隐藏目标标记、教程提示、对白和跳过按钮。
6. 暗幕用 `0.5` 秒淡出。
7. 保存 `ready_to_depart` 后再提交 `chapter_1_done=true` 与兼容字段 `tutorial_done=true`，最终阶段为 `done`。

## 7. 最终验收矩阵

1. **新档正常路径**：序章结束后进入第一章；按七阶段顺序完成，经营状态与剧情一致；第一章结束仍在餐厅。
2. **逐字与锁定**：对话的第一次输入补全文字、第二次推进；锁定期间方向键/WASD 不移动主角。
3. **镜头与铁山**：核对目标坐标、倍率、两个时长、正式 PNG、姓名揭示时机和回镜。
4. **真实首单**：订单、材料、配方、成品、交付和声望均有状态证据；Toast 只作为反馈，不作为成功依据。
