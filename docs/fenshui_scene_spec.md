# 分水庭整图规格：岸水保护、范围借电与巨蛙反击

2026-10-29。用户已确认规格范围与验收入口。本文件综合既有对齐记录和最新会话，不表示游戏实现完成，也不代替实施票据的放行。

## 问题陈述

玩家需要在分水庭体验一段有巧思、可自主选择的冒险，而不是在浅水中承受高频围攻或被强制清场。现有隔离试玩验证过锁向冲刺和局部借电，但不覆盖正式整图的水中保护、上岸机会、巨蛙反击及其完整恢复。已制作的美术演示还用指向鱼的电弧表达放电，容易把范围技能误读成单体攻击。

## 解决方案

让岸与水直接改变战斗机会：魔物水中有可见保护膜，玩家可引鱼上岸，或借雷鳗范围放电短暂消除保护；随后自主挑战可绕行的巨蛙，在其腾空时攻击使其翻倒露腹。保留采集、宝箱、剧情与区域通路，让玩家通过观察创造机会，不要求特定角色或极短时机。动作、膜层、范围预警、伤害与恢复必须一致。

## 实现决策

### 规则与状态

- 保护膜是水中防御保护的视觉表现，不是独立盾生命。三种魔物在有效保护下承受正常伤害的25%，有效攻击最低1；此为首版试调起点，不调整基础生命、攻击与捕获概率。
- 离水取消保护；回水凝膜1秒。雷电破膜4秒，重复命中刷新不累加，回水不能提前覆盖破膜窗口。
- 雷鳗释放在实际范围内一次结算；鱼和巨蛙受电伤并破膜，自身及同类免疫。玩家受电沿用现有伤害与防御规则，岸上不受水面导电伤害。
- 放电为局部水面范围技能，不是单体连线，也不是全水池无界通电。范围预警、扩散电纹与命中使用同一有效区域口径；岸、岛、栅栏截断，不通过美术外延扩大判定。
- 鱼锁向冲刺可上岸；雷鳗短距离追上岸，岸上不能放电。岸上停顿2.5秒后尝试合法回水，不无限追击、不瞬移，回水中仍可受伤。
- 巨蛙腾空反击窗口约0.8秒，任何实际命中的玩家攻击可触发；不限定角色或背后攻击，环境电不能触发击飞。
- 巨蛙露腹3秒，取消保护、承受正常伤害2倍，不回血；起身后按所在地形与未结束的破膜状态决定保护。
- 巨蛙仅脱战回水安静2秒后每秒恢复最大生命5%，最高满血，重新交战立即停止；正常交战落水、腾空与露腹不回血。
- 普通鱼鳗保留本趟受伤，脱战恢复活动；已处理的不重生，新探索才重置。
- 复用探索、伤害、怪物动作显示、捕获结算与存档模块。状态须支持检查点恢复、剩余计时及保存失败回滚；具体新增字段在实施时确定，不在规格中预造接口。
- 暂停、地图、弹窗与离线不推进战斗计时；读档不重抽捕获结果、不重复扣费或发奖。

### 整图与剧情

- 正式整图保留4鱼、2鳗、1巨蛙，普通怪分两组，每组2鱼1鳗。首遇以场景演示为主，短提示兜底；不暂停讲长教程。
- 第一组支持先引一鱼上岸，再接触借电；第二组可适度变化，但只使用验证过的合法候选点，不在整片水域盲抽。
- 巨蛙为可绕行小高潮，不作盐池或青苔池通行门槛，不清场、不暂停整图。通过布局避免默认混战，玩家主动引来的鱼鳗仍可参与借电。
- 保留底图、玩家浅水65%速度、既有连接、资源宝箱数量和奖励。资源与剧情保护边界不能静默删除或缩小。
- 御风和萨莉亚切磋独立，不参与普通借电或巨蛙战；剧情后保留探索状态。切磋结束生命按开始时当前生命的10%，保留赠礼与便当内容。

### 素材与表现

- 保护膜使用image2生成的独立透明位图叠加；程序控制动作跟随、层级、渐显和碎散，不以程序重画膜面代替已确认制作方式。
- 主体与膜共享动作、方向、帧号、缩放和锚点。不得把鱼游动膜硬套攻击姿态，也不能靠延长静帧冒充连续动作。
- 雷鳗收身蓄电、伸展释放，水面电纹向周围扩散，命中对象各自闪白、电花与破膜；不画目标锁定连线或方向箭头。方向预警保留给鱼冲刺。
- 巨蛙新制连续起跳、空中伸展、受击失衡、翻倒、露腹呼吸、起身动作，保持原外观、体型和四向一致；食材肚皮图不能作为角色露腹动作。
- 生图采用飞书对应风格提示词原文并记录来源，按已确认的提示词及改稿范围执行；缺失内容先核对，不用概括的“水彩风”替代。
- 已有雷鳗三动作48帧膜层、短放电和鱼游动膜可复用，但素材存在不等于接入通过。定向传播演示必须修订；其他鱼动作膜与巨蛙新动作仍有缺口。

## 测试决策

- 用户已确认以正式分水庭场景的玩家操作作为主要验收入口，尽量复用现有内部输入和跨进程恢复入口，不另建与正式战斗脱节的演示逻辑。
- 测试外部结果：实际生命变化、位置是否合法、保护是否可见、动作与窗口是否同步、输入是否恢复、奖励是否只结算一次；不以字段存在或截图文件生成作为通过依据。
- 单元测试先于实现。通过既有战斗推进接口检查保护伤害、单次范围伤害、多目标、同类免疫、破膜刷新、凝膜优先级和巨蛙反击/回血条件。
- 正式场景覆盖水中与岸上攻击、锁向冲刺、鳗岸上禁电、合法回水；范围中心/边界/范围外与隔岸目标；一次放电影响多个目标，余电不再扣血。
- 覆盖多怪多技能重叠时移动、攻击、冲刺、技能切换、捕获成功/失败/取消、奖励收下与重复领取拒绝。记录帧耗时和卡住证据，不把单次测试外推为所有机器性能保证。
- 覆盖巨蛙不同玩家攻击打断、环境电不触发打断、露腹增伤、正常落水不回血、脱战回水延迟回血及重新交战中断。
- 在保护、凝膜、破膜、搁浅、腾空、露腹、回水和回血阶段保存并跨进程恢复；检查旧档、保存失败回滚、离线与弹窗计时冻结以及捕获事务不重复。
- 从真实入口验证首遇顺序、两组分隔、资源可达、剧情隔离、巨蛙可绕、盐池与青苔池往返；巨蛙西侧历史路径失败必须复验，不能删除失败样例代替修复。
- 两种分辨率亲看截图或录像，审阅角色比例、膜透明度、范围边界、连续动作和多怪可读性；自动数值检查不能代替视觉判断与用户最终观感。
- 测试只用Godot内部输入，隔离存档和环境，窗口不可获取焦点；不得使用系统鼠标定位、按键注入或抢焦点。
- 先例包括引鱼借电试玩的行为测试、真实场景交互测试、旧档跨进程恢复及地图通路检查。其历史通过只证明旧范围，不作为本规格已通过的证据。
- 完成必须在实际目标主目录增量集成后重新验收，保留所有非本任务用户改动；无头启动或独立工作树通过不替代主目录集成验收。

## 范围外

- 不重做其他地图、小屋、园圃、餐厅教程、经营系统或插件。
- 不新增奖励货币、材料、菜谱、盾生命条，也不重调基础生命、攻击和捕获概率。
- 不实现无界全水域传播，不将借电改成指向性技能，不引入强制清场门槛。
- 不把音效采购或完整音效制作纳入本规格默认交付；现有音源未核验，缺失时披露无声边界。
- 本次只发布规格和分批建议，不创建执行任务、不修改游戏、不生成新素材、不提交或推送代码、不修改飞书。
