# 序章关键帧生成提示词

本清单记录正式成片采用的提示词方向。图像由 Codex 内置 ImageGen 生成，
主角设定图和芽芽设定图只用于锁定角色，画风参考图只用于约束绘画语言。

## 共用约束

- 用途：PC 游戏开场视频关键帧，16:9 横屏
- 媒介：手绘 2D 水粉/厚涂绘本，大色块，少描边，轻微纸张和干刷纹理
- 构图：电影式景深，主体轮廓清楚，下方保留字幕安全区
- 排除：3D、写实摄影、赛璐璐粗描边、可读文字、水印、Logo、UI、边框、血腥表现
- 主角不展示清晰正脸；以背面、侧背、兜帽阴影、蒸汽或逆光遮挡
- 深层异常只展示根须、局部发光组织和水面，不展示完整生物或生命循环

## 镜头提示词

1. **古老王国**：暮色山谷中的古老王国，浅色石砌王城、高架水道与旧塔楼，窗口有细小暖光。
2. **历代国王**：火把照亮画像长廊，六位国王来自不同时代、服饰和冠冕各异，面容却几乎相同。
3. **三种传说**：相连的壁画空间表现发光血脉、同一剪影更换仪式面具、古代延寿泉或炼金容器。
4. **王国覆灭**：同一王城在风暴、尘埃和崩塌中消失；无人群伤亡画面，只表现失落和谜团。
5. **王陵发现**：地震裂开山体，冒险者持灯进入古代王陵；华丽棺椁全部打开且空无一物。
6. **石碑**：空棺之间的古老石碑特写，表面只有磨损凹槽和两块留给后期碑文的空白刻面。
7. **迷宫综合症**：深层营地里多名成年冒险者虚弱颤抖，面包、汤和药物无人触碰；不出现主角。
8. **魔物肉奏效**：濒死冒险者吃下熟制魔物肉后恢复，伙伴惊讶；主角在画面边缘背光观察。
9. **尝试料理**：主角以三分之二背面在洞窟炉火旁料理魔物肉，蒸汽遮脸，周围有盐、香草和旧地图。
10. **递给芽芽**：暖色洞窟营地中，主角跪下把热汤递给芽芽；只出现这两个角色。
11. **深层异常**：主角和芽芽站在异常空间门槛，只见发光根须、石缝局部组织与黑色水面。
12. **记忆碎裂**：主角触碰未知根状物后身体透明并碎裂；碎片中仅有灶火、餐厅、旧地图和递出的碗，芽芽抱住她。
