# 首次探索教学限制

2026-11-09规则更新：首次探索以成功带回食材并返回餐厅为完成条件。战败回档取代旧版保留损失、继续检查点规则。白虎任务定义及奖励数量不变。

首章完成后，餐厅显示“前往迷宫探索”。允许查看已解锁食谱、当前任务、移动和迷宫入口；营业牌及其他经营入口在首探完成前保持限制。迷宫内仍禁止放弃返程及进入下一地区。首探捕获沿用已有隐藏成功规则，操作教学不能跳过。

## 战败回档

capture_run.begin 创建首探前，将入场前存档及当时各角色饱腹度写入 first_exploration_checkpoint_v1。快照随同入场事务保存，不包含自身；恢复同趟探索不覆盖快照。首探战败由 finish 在同一保存事务中恢复快照，撤销本趟捕获、采集、任务、奖励和消耗，回到餐厅；入场前餐厅状态保留。保存失败恢复失败前全部状态，允许重试，不产生部分回档。

恢复后清除本趟运行、首次进入标记、探索教学已读记录及经营教学待播状态；首次门禁仍为 active。无论失败多少次，重进重新建立全部迷宫教学，饱腹度不因失败减少。first_exploration_retry_notice 保存本次返店待播提示，芽芽每次说：“迷宫的魔物还是有些凶险，注意走位和战斗方式，再进迷宫试试吧。”读完才清除，读档不丢失未读提示。

旧首探存档没有快照：按用户明确授权重置到首章完成基线，保留存档身份、首单完成凭证和首章出发状态，金币及声望恢复首单凭证数值；重置首探奖励、采集、角色成长等后续状态。旧档当前仍在探索时于战败处理；旧档已战败返店时在下次开始探索处理。已完成首探的普通存档不适用该重置。

## 成功返程与第一天菜单

首次正常结束探索必须完成白虎任务、有本趟捕获食材，且仓库与本趟食材合计能制作至少一道已解锁的营业料理。缺少条件则保留探索。成功入仓后同一事务解除门禁、删除快照并安排首次经营教学；先确认食材结算，再播放经营对白并打开第一天菜单。

第一天菜单隐藏“稍后”，Esc及直接关闭不能绕过；选择至少一道可做料理并成功提交营业后关闭。保存失败保持菜单可重试。后续天数沿用原准备期和菜单规则。后续探索战败不再回档首探。
