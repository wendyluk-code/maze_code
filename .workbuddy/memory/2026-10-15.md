- 证书方案升级为本地 CA 链：`build/certs/ca.cert.pem`（CN=MazeCode Local Dev CA，CA:TRUE critical）签发服务器证书（SAN=IP:10.11.178.153/127.0.0.1/localhost）。`certutil -user -addstore Root ca.cert.pem` 装入**当前用户**受信任根（无需管理员）。Chrome 严格模式下验证通过，警告消失。其他局域网设备：把 ca.cert.pem 发给对方导入信任存储，或点"继续前往"。
- 画布尺寸坑：`canvas_resize_policy` 三档——0=Disabled（Godot 不管，canvas 停在 HTML 默认 300×150，画面缩成角标）；1=Project Settings（按项目 viewport 固定尺寸，不随窗口缩放）✅；2=Adaptive（填满窗口）。"固定原本大小"必须用 1，不能用 0。
- 终态：canvas 固定 1152×648（CSS 同），800×500 与 1280×800 两种视口下尺寸不变，引擎正常、画面完整。
- 已知无害现象：线程版 shell 会按 emscriptenPoolSize=8 请求 8 次 index.js（pthread worker 池）；大文件流式下载读完时 playwright 报 ERR_ABORTED，属正常标记。自签 CA 无 CRL，Windows schannel curl 需 `--ssl-no-revoke`，Chrome 软失败不受影响。

## 三次迭代：画布浏览器居中

- 用户反馈固定尺寸后画布贴左上角。修复：export_presets.cfg 的 `html/head_include` 注入 `<style id='center-canvas'>html,body{min-height:100vh !important}body{display:flex !important;overflow:auto !important}#canvas{flex:0 0 auto !important;margin:auto !important}</style>`（单引号避 ConfigFile 转义，!important 保证覆盖默认 shell 样式，与导出顺序无关）。
- 关键点：居中用 `margin:auto` 而非 justify-content/align-items:center——后者在窗口小于画布时会产生负溢出裁掉左边缘，margin:auto 会优雅退化为贴边+可滚动（overflow:auto）。
- 验收：1280×800 下 offset=(64,76) 恰为居中值；800×500 下贴边可滚动。配置持久化在 export_presets.cfg，重新导出自动生效。
